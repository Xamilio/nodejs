Галерея малюнків сервера

Малюнки різних форматів (SVG, PNG, JPG, WEBP), збережені в папці src/images та віддані сервером Node.js

.SVG Format

Векторний баннер

Формат SVG (Scalable Vector Graphics) — чітка векторна графіка будь-якого масштабу.

.PNG Format

Фірмовий бейдж

Формат PNG (Portable Network Graphics) — підтримує прозорість та високу якість.

.JPG Format

Читальний зал

Формат JPG (Joint Photographic Experts Group) — оптимальне стиснення для фотографій.

.WEBP Format

Затишний лаунж

Формат WEBP — сучасний високоефективний формат веб-зображень від Google.
